My Little Garden

Gardening simulation game where players plant, water, and harvest plants in a peaceful garden setting. 
With simple controls and a relaxing atmosphere, the game lets players grow their garden at their own pace while unlocking 3 new seed types over time. 
Player begins with one seed type to plant it in the garden. After planting, the seed requires one watering within 60 seconds or it will die. Once watered, 
the plant will grow and becomes ready to harvest in 5 second. Harvesting a set number of plants unlocks the next seed type. This loop continues until all 
four seed types are unlocked.

How to play?
Select “PLAY” button to start game
Select “QUIT” button to exit game
Use Music Volume slider to control music volume of the game
Select “PAUSE” button to pause game
Select “RESUME” to return to gameplay
Player’s  movement
A – move left, D – move right, W – move forward, S – move backward
Must collide with the Dirt tiles to use the following keys
E -  Open Seed selection window
Q - Water plant
F - Harvest plant
In seed selection window, select available seed, select “SELECT” to place seed or select “CANCEL” to cancel.
